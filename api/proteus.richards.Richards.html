class proteus.richards.Richards.ThetaScheme(transport, integrateInterpolationPoints=False, theta=1.0)[source]

Bases: BackwardEuler

Two-level theta method for the Richards LevelModel.

The storage term is always (m(u^{n+1}) - m(u^n))/dt; the Galerkin flux terms are weighted theta*F(u^{n+1}) + (1-theta)*F(u^n). theta = 1 (default) is backward Euler and theta = 1/2 is Crank-Nicolson. Set it in the numerics file with timeIntegrationTheta = 0.5.

With STABILIZATION_TYPE=0 the theta weighting applies to the Galerkin element integrals (exterior boundary fluxes stay implicit). With the edge-based schemes the low-order operator stays backward Euler and theta enters only the high-order flux used to build the FCT correction.

Set flags that indicate that all terms are implicit.

Notes

The constructor sets the input arguments, calculates dimensions, and allocates storage. The meanings of variable suffixes are

  • global – per physical domain

  • element – per element

  • elementBoundary – per element boundary

The prefix n means ‘number of’.

Storage is divided into quantities required at different sets of points or geometric entities. Each type of storage has a dictionary for all the quantities of that type. The names and dimensions of the storage dictionaries are

  • e – at element

  • q – at element quadrature, unique to elements

  • ebq – at element boundary quadrature, unique to elements

  • ebq_global – at element boundary quadrature, unique to element boundary

  • ebqe – at element boundary quadrature, unique to global, exterior element boundary

  • phi_ip – at the generalized interpolation points required to build a nonlinear phi

checkFCTParallelLayout()[source]

Refuse a partition on which an OWNED DOF misses part of its element star.

The FCT limiters (both FCT_TYPEs) are nonlinear in the assembled rows (ML, MC, the flux matrices, P_i, Q_i), so a row must be complete at every owned DOF. An additive residual does not need this, which is why Galerkin and the low order still agree with serial on such partitions. Element partitioning with nLayersOfOverlapForParallel = 0 violates it: a node on the cut is owned by one rank but sees only that rank’s elements (Hornung-Messing h = 1/16, 2 ranks: WRR FCT 2.8e-3 vs 6.8e-5 serial). Element partitioning with overlap >= 1 and node partitioning both pass.

Test: ownedElementStarsIncomplete().

ownedElementStarsIncomplete()[source]

Global number of owned DOFs whose element star is not entirely on their rank (0 in serial).

The number of local elements containing each owned DOF must equal its global count, which is assembled by a reverse-add of the counts over the uniquely owned elements (eN < nElements_owned). Rows of element-assembled matrices (ML, MC, …) are complete at owned DOFs exactly when this is 0.

femL2Norm(x, lumped=False)[source]

Finite element L2 norm of a nodal vector x (free DOFs, local numbering with ghosts).

||x||_{L2} = sqrt(sum_{i owned} x_i (M_C x)_i), M_C the consistent mass matrix, i.e. the L2(Omega) norm of the finite element function with these nodal values (the quantity MFEM’s GridFunction::ComputeL2Error(0) evaluates). lumped=True uses M_L instead. x must hold current ghost values. The consistent version needs complete rows of M_C at owned DOFs (node partitioning, or element partitioning with overlap >= 1); it raises otherwise. Used by NonlinearSolvers for unorm = ‘L2’ / ‘L2_lumped’.

ghostScatter(*arrays)[source]

Forward-insert (owner -> ghost copy) each free-DOF array. No-op in serial.

With one layer of overlap only the OWNED DOFs have their full element star and their full set of boundary faces on this rank, so anything built by a loop – mDotLow, min/max_m_bc, the Zalesak ratios – is incomplete at a ghost DOF. The edge loops read those arrays at the COLUMN j of an owned row i, and j can be a ghost, so without this the two ranks sharing a cut edge build different f_ij, the antisymmetry f_ij = -f_ji is lost and the correction manufactures mass along the partition. The owner always holds the complete value, so an insert scatter repairs every ghost.

u[0].par_dof is the only ghosted vector this module owns, so the arrays are shuttled through u[0].dof (the same idiom as mphase_co2/m_comp_co2). Integer arrays round-trip exactly: they only ever carry small whole numbers (0/1 flags, material indices).

exportTransportFluxes()[source]

Realized fluid exchanges of the step just accepted, for the compatible transport.

With E~_ij the row-i edge flux the residual used (low order, plus alpha_ij f_ij / dt when the FCT correction was applied) and b_i the boundary integral (into the domain), the accepted step satisfies, up to the solver residual r_i,

M_L,i (m_i^{n+1} - m_i^n) / dt = sum_j E~_ij + b_i - r_i.

E~ is antisymmetric except on faces with a weak Dirichlet condition, whose penalty and adjoint terms enter the stiffness matrix unsymmetrically, so the export splits it into E_ij = (E~_ij - E~_ji)/2, which the transport uses, and the symmetric remainder, which the transport sees as boundary exchange through B_i = M_L,i dm_i/dt - sum_j E_ij. Espatial is E without the consistent-mass part of the correction; the transport reconstructs its dispersion velocity from it.

m^n is the old-time mass this step balanced, rho_T(c^n) theta(p^n). The transport adds exactly this increment to its carried storage, so the two balances agree. (Taking m^n from the previous step’s m^{n+1} instead turns every concentration change into a fluid source M_L (rho_T(c^n) - rho_T(c^{n-1})) theta / dt: at a strongly imposed concentration node in the first steps of the levee case, dt = 1e-8 d, the flow Newton cannot absorb it.)
