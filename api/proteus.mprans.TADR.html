proteus.mprans.TADR.checkCoupledQuadrature(modelA, nameA, modelB, nameB)[source]

Verify two coupled models share a mesh and one quadrature rule.

Coupled fields (velocity, water content, density) are passed between models as bare quadrature arrays indexed by eN*nQuadraturePoints_element+k, so both sides must agree on the quadrature or the receiving kernel reads the wrong entries – or past the end of the array.

nQuadraturePoints_element is NOT a shared setting: OneLevelTransport builds it per model in Quadrature.buildUnion over that model’s own integral keys, plus any (‘stab’,..)/(‘numDiff’,..) rules and the Lobatto points that massLumping/reactionLumping inject. Two models handed the identical elementQuadrature object can therefore still end up with different point counts, and unions of equal size can order their points differently, which scrambles the coupled fields within each element without changing a shape. So compare the reference points themselves, not just their count.

Called from attachModels on both sides of the Richards <-> TADR coupling, where the aliases are formed and before any kernel indexes them.

Notes

The constructor sets the input arguments, calculates dimensions, and allocates storage. The meanings of variable suffixes are

  • global – per physical domain

  • element – per element

  • elementBoundary – per element boundary

The prefix n means ‘number of’.

Storage is divided into quantities required at different sets of points or geometric entities. Each type of storage has a dictionary for all the quantities of that type. The names and dimensions of the storage dictionaries are

  • e – at element

  • q – at element quadrature, unique to elements

  • ebq – at element boundary quadrature, unique to elements

  • ebq_global – at element boundary quadrature, unique to element boundary

  • ebqe – at element boundary quadrature, unique to global, exterior element boundary

  • phi_ip – at the generalized interpolation points required to build a nonlinear phi

ghostScatter(*arrays)[source]

Forward-insert (owner -> ghost copy) each DOF array. No-op in serial.

With one layer of overlap only the OWNED DOFs have their full element star on this rank, so anything built by a loop over elements or rows – uLow on the explicit paths, the Zalesak ratios – is incomplete at a ghost DOF, and FCTStep reads those arrays at the column j of an owned row i. The owner always holds the complete value, so an insert scatter repairs every ghost. Shuttled through u[0].dof, the one ghosted vector this model owns (as in Richards.ghostScatter).
